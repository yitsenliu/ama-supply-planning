# AMA 產銷協調中心（GitHub Pages 靜態版）

國際精工產銷、採購與生產的協調看板。讀取採購由 ERP 匯出整理的「國工產銷預估／庫存／排程／BOM 成本」Excel，拆成三層呈現：

1. **ERP 原始層**：ERP庫存、ERP在途、ERP未進貨，以品項編碼合併。
2. **BOM 齊套層**：8 張 BOM 庫存表；讀取 Excel 公式，追溯每個料件需求來自哪些成品型號，並檢查尺寸／顏色／有無燈是否一致。
3. **成品產銷層**：產銷表、次月預估、產能排程、成本表。

## 頁面

總覽與會前重點｜本月產銷｜次月預估｜產能排程｜BOM 齊套｜ERP 物料查詢｜成本分析｜資料邏輯／ERP 串接｜原始工作表

「資料邏輯」頁列出原表公式、驗算結果、公式疑點，以及串接 ERP 原始資料的建議步驟；可下載「型號 → BOM 料件」需求對照表作為串接初稿。

## 資料安全

- 公開倉庫只放 `data/data.enc.json` 密文：PBKDF2-SHA256（1,200,000 次）推導金鑰，AES-256-GCM 加密。密碼不寫入程式、倉庫或建置紀錄。
- 解密與 Excel 解析都在使用者瀏覽器內完成；「匯入新 Excel」不會上傳檔案。
- `電控BOM` 的供應商聯絡帳號、地址與聯絡人欄位在解析時即移除。
- 此版為**單一密碼的靜態快照**，沒有個人帳號與角色權限；持有密碼者可看到成本與供應商資料。需要依角色區分時，請使用多人雲端版或後續的正式平台。
- 純數字短密碼可被離線暴力破解；正式使用前建議改為 12 碼以上英數混合密碼並重新建置。

## 更新資料

```bash
npm install --ignore-scripts
AMA_SITE_PASSWORD='新密碼' node scripts/build-data.mjs "/路徑/產銷檔.xlsx"
node scripts/check.mjs
```

`build-data.mjs` 解析後加密寫入 `data/data.enc.json`，並重新解密比對。`check.mjs` 檢查倉庫內沒有 Excel、未加密 JSON 或明文資料。Excel 檔已列入 `.gitignore`。

## 技術

純靜態 HTML／CSS／JavaScript，無建置步驟；`js/parser.js` 在 Node 與瀏覽器共用。Excel 解析使用自帶的 SheetJS Community Edition 0.20.3（`vendor/`，Apache-2.0），只在匯入 Excel 時載入。頁面設定 CSP，只允許同源資源。

## 計算口徑

- 月需求餘量 = 總需求 ÷ 工天數 × 剩餘工天。
- 產銷差異 = 總庫存 + 預計生產 + 託外生產 − 月需求餘量。
- 可支應台數 =（庫存 + 在途）÷ BOM量；差異 = 可支應台數 − 需求台數；未進貨另列。
- 網站顯示 Excel 儲存的計算結果，不重算原表；公式只用來追溯來源與檢查。
